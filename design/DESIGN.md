# Huginn 디자인 기준

표시 이름은 **Huginn(후긴)**입니다. 여러 AI가 맡은 작업과 되돌려 준 결과를 한곳에서 확인하는 앱입니다.

## 앱 아이콘

2026-11-19 사용자가 **2번 Twins**를 선택했습니다. 아이보리 타일 위에 마주 보는 먹색 까마귀 두 마리, 중앙의 금색 매듭, 아래 가지가 있는 원본을 그대로 사용합니다. 선택한 구도와 문양을 재해석하거나 다시 생성하지 않습니다.

정본은 `app/brand.json`이 가리키는 PNG이며, 승인 원본은 `문서/AI_Desk/작업_보드/디자인/Huginn_아이콘_시안_5종/02-twins.png`입니다. 웹·파비콘·macOS·Windows는 같은 원본에서 크기와 형식만 변환합니다. 프롬프트와 승인 정보는 `app/assets/icon-prompt.txt`에 기록합니다.

## 화면

Twins 아이콘의 아이보리·먹색·황동색을 앱 전체에 적용합니다. 기존 다크 구조를 유지하면서 푸른 회색을 따뜻한 먹색으로, 파란 조작 강조를 차분한 금색으로 바꿉니다. 장식 문양이나 종이 질감을 화면 배경에 반복하지 않습니다.

색상 구현 정본은 `desktop/theme.css`입니다. 작업 현황·통계·설정·작업 기록은 `/assets/theme.css`를 통해 같은 파일을 읽고, 네이티브 오류 화면에도 같은 파일을 내장합니다. HTML 안에 별도 색상 토큰을 덧붙이지 않습니다.

2026-11-19 사용자 요청으로 잘 보이지 않던 색을 보정했습니다. 진행(금색)·응답 대기(주황)·실패(산호 빨강)·완료(초록)의 색상 간격을 벌리고, 그래프 정보색은 금색·초록과 겹치지 않는 차분한 청회색을 씁니다. 비활성 글자와 구분선은 배경 대비를 높였습니다. 글자로 쓰는 토큰은 두 모드 모두 바탕·카드·입력 표면에서 대비 4.5 이상입니다.

라이트 모드는 아이콘의 아이보리를 바탕으로 같은 의미색을 어둡게 조정한 묶음이며 `:root[data-theme="light"]`에 정의합니다. 사이드바 하단의 전환 버튼으로 바꾸고 선택은 브라우저 저장소 `wb.theme`에 기억합니다. 작업 현황과 작업 기록은 첫 그리기 전에 저장된 선택을 적용합니다. 기본값은 다크이며, 네이티브 창의 첫 배경색은 다크 바탕을 유지합니다. 라이트 모드에서는 아이보리 앱 아이콘이 바탕에 묻히지 않도록 얇은 테두리를 둡니다.

설정의 **화면** 탭은 Slack의 모양 설정처럼 밝기(시스템 설정·다크·라이트)와 테마 카드로 구성합니다. 테마는 Slack의 다섯 묶음(음악에서 고른 색 6·단일 색상 8·시력 보조 색상 2·새로운 조합 12·다시 만든 클래식 6)을 이름만 바꿔 옮기고 Huginn 기본을 더한 35종입니다. 각 카드는 원본의 두 색을 잇는 원형 견본과 이름을 보여 줍니다. 원본 색이 Huginn 화면에서 읽히지 않으면 같은 색상·채도에서 명도만 조정합니다. 테마는 사이드바 색의 색상으로 화면 전체를 다시 칠합니다. 바탕·패널·선택·구분선은 사이드바 색상과 사이드바 채도의 80%(최대 60%)로 칠해 본문도 사이드바와 같은 색 계열로 보이게 하고, 다크에서는 사이드바가 밝을수록 바탕도 함께 밝아집니다. 글자는 같은 색상에 채도를 20% 이하로 둡니다. 글자, 진행·대기·막힘·완료·안내 색, 다크·라이트별로 테마가 정한 강조색은 새 바탕·패널에서 4.5:1 이상이 될 때까지 명도만 조정합니다. 시력 보조 테마는 상태색 자체를 구분하기 쉬운 색으로 바꾸며, 상태 이름은 항상 함께 표시합니다. 사이드바가 없는 Huginn 기본은 원래 색을 그대로 씁니다. Slack 사용자 지정 테마와 같이 시스템 내비게이션(사이드바)·선택한 항목·접속 표시·알림 색을 테마마다 따로 둡니다. 선택한 항목은 사이드바의 선택 세션·메뉴 바탕이며 글자는 흑백 중 대비가 큰 쪽을 씁니다. 접속 표시는 작업 중 세션 점, 알림은 응답 대기 세션 점이고 사이드바와 3:1 이상 대비가 나야 합니다.

`desktop/theme.css`는 다크·라이트 원본 값을 `--d-*`·`--l-*` 상수로 두고, 화면 토큰(`--bg`·`--primary` 등)이 이 상수를 가리킵니다. 테마는 `html:root`에서 상수만 덮어쓰고, 사이드바가 칠해지면 `data-side-scheme`으로 사이드바 안쪽만 사이드바 밝기에 맞는 다크·라이트 토큰을 씁니다. 사이드바 안의 패널·구분선·선택 색은 사이드바 색과 글자색을 섞어 만듭니다. 밝기는 `wb.theme`, 테마는 `wb.palette`, 사용자 지정 테마는 `wb.customTheme`에 저장하고, 첫 그리기 전 적용을 위해 만든 CSS를 `wb.paletteCss`·`wb.sideScheme`에 둡니다. 첫 화면 스크립트는 `html:root{…}` 형식의 색 선언만 받아들입니다.

사용자 지정 테마는 색 선택기 또는 JSON(`name`·`sidebar`·`selected`·`presence`·`notification`·`accent`·`status`)으로 만들고 붙여 넣기·`.json` 파일로 받습니다. **공유**는 현재 테마를 같은 JSON으로 복사합니다. 모든 색은 `#RRGGBB`이며, 강조색·상태색은 두 모드의 바탕·패널과, 사이드바는 사이드바 보조 글자와 4.5:1 이상 대비가 나와야 적용합니다. 기본 테마 전체도 같은 기준을 시험으로 확인합니다.

상태색은 성공·대기·실패를 구분하기 위한 의미색입니다. 텍스트와 상태 이름을 함께 표시합니다. 세션 아이콘은 금색·아이보리·보조색만 사용하며 이전의 보라·분홍·파랑 개별 세션 색 캐시도 교체합니다. 그래프 면·상태 배경은 정본 색의 12~16%, 강조선은 35~45%, 중립 트랙은 아이보리의 7%를 사용합니다. 상세 패널 덮개는 바탕색의 70%, 스킬 대화상자 덮개는 검정의 50%, 그림자는 검정의 40~50%입니다.

Pretendard와 기존 시스템 글꼴 대체, 본문 14px·보조 12px, 간격 4·8·12·16·20·32px, 카드 반경 16px·입력 4px·버튼 5px는 유지합니다. 포커스 테두리는 금색 2px입니다. 기본 조작은 금색 테두리, 선택 상태는 따뜻한 표면과 금색 테두리, 활성 스위치 손잡이는 먹색으로 충분한 대비를 확보합니다.

앱 표시 이름과 실행 식별자·데이터 폴더는 Huginn입니다. 기존 `wb` 명령과 서비스 주소는 유지합니다. 네이티브 창의 초기 배경은 `bg`와 같은 먹색을 사용합니다.

## 시안 비교 문서

형태 5종과 Crossing 색상 5종의 기존 비교 HTML은 검토 기록으로 보관합니다. 최종 제품은 사용자가 선택한 Twins 원본을 따릅니다.

2026-11-19에는 단독 까마귀·두 까마귀·매듭·뿌리·문장 5개 방향을 단일 HTML로 비교했습니다. 이미지가 문서 안에 포함되어 있으며 밝은/어두운 배경, 16·32·64px, 원본 확대를 제공합니다. 이 문서는 승인 당시의 비교 기록으로 유지하며 제품의 공통 색상 파일과 연동하지 않습니다. 뿌리형 후보의 짙은 녹색 `#13221f`도 비교 이미지에만 사용합니다.

## macOS 드래그 설치 창

DMG는 Finder의 실제 `Huginn.app`과 `Applications` 폴더 바로가기를 표시합니다. 두 아이콘을 배경 이미지에 그려 넣지 않습니다. 새 까마귀 앱 아이콘을 쓰며 볼륨 아이콘도 같은 ICNS를 사용합니다.

기본 밝은 Finder에서도 파일명이 읽히도록 배경은 아이콘의 아이보리에 맞춘 `#ece5d5`, 제목과 화살표는 먹색 `#24221d`, 보조 문구는 `#625b4e`입니다. 먹색·금색 `#a88b4f`은 제목 위의 짧은 선에 사용합니다. 그라데이션·카드·그림자·마케팅 문구는 추가하지 않습니다.

## 위임 작업

부모 상세에서 위임 목록은 기본 접힘이며 사이드바에 완료 알림을 추가하지 않습니다. 목록 머리에는 개수와 작업/대기 상태를 작은 선 아이콘과 텍스트로 표시합니다. 항목을 열면 위임 지시와 결과가 나란히 보이고 좁은 화면에서는 세로로 쌓입니다. 긴 원문은 내부 스크롤하며, 기록이 없으면 미확인으로 표시합니다. 기존 Pretendard·본문 14px·보조 12px·간격 8/12/16/20px와 표면색을 재사용합니다. 원문은 HTML로 실행하지 않고 텍스트로 표시합니다.
