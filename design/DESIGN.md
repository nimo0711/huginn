# Moa 디자인 기준

기존 화면의 Pretendard, 다크 배경 `#0c0e16`, 표면 `#14171d`, 텍스트 `#eeeeee`, 기본 강조색 `#4c6df1`을 유지합니다. 간격은 4·8·12·16·20·32px, 카드 반경은 16px, 입력은 4px, 버튼은 5px입니다.

사용자가 승인한 이름은 **Moa**, 한국어 표기는 **모아**입니다. 여러 AI 세션의 작업을 한곳에 모아 보는 앱입니다.

심벌은 두 개의 수직 작업 흐름이 가운데에서 만나는 M입니다. 기존 강조색 배경과 밝은 선만 사용합니다. 그라데이션·광원·그림자·추가 상태색은 사용하지 않습니다.

아이콘 정본은 `app/brand.json`입니다. 64 단위 좌표계에서 배경은 6 단위 여백과 12 단위 반경, 심벌은 7 단위 굵기를 사용합니다. 작은 Dock 아이콘에서도 M이 구분되게 하는 그림 자체의 비례이며 화면 컨트롤 크기 규칙과 별개입니다. 웹 SVG와 macOS 아이콘은 같은 좌표·색상을 읽습니다.

앱 표시 이름은 `app/Info.plist`, 화면 표시 이름은 HTML 제목과 헤더에 적용합니다. 실행 식별자, DB 경로, 기존 `wb` 명령, 서비스 주소는 표시 이름과 분리합니다.
