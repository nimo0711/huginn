# Huginn 디자인 기준

표시 이름은 **Huginn(후긴)**입니다. 여러 AI가 맡은 작업과 되돌려 준 결과를 한곳에서 확인하는 앱입니다.

## 앱 아이콘

2026-11-19 사용자가 **2번 Twins**를 선택했습니다. 아이보리 타일 위에 마주 보는 먹색 까마귀 두 마리, 중앙의 금색 매듭, 아래 가지가 있는 원본을 그대로 사용합니다. 선택한 구도와 문양을 재해석하거나 다시 생성하지 않습니다.

정본은 `app/brand.json`이 가리키는 PNG이며, 승인 원본은 `문서/AI_Desk/작업_보드/디자인/Huginn_아이콘_시안_5종/02-twins.png`입니다. 웹·파비콘·macOS·Windows는 같은 원본에서 크기와 형식만 변환합니다. 프롬프트와 승인 정보는 `app/assets/icon-prompt.txt`에 기록합니다.

## 화면

Twins 아이콘의 아이보리·먹색·황동색을 앱 전체에 적용합니다. 기존 다크 구조를 유지하면서 푸른 회색을 따뜻한 먹색으로, 파란 조작 강조를 차분한 금색으로 바꿉니다. 장식 문양이나 종이 질감을 화면 배경에 반복하지 않습니다.

색상 구현 정본은 `desktop/theme.css`입니다. 작업 보드·통계·설정·작업 기록은 `/assets/theme.css`를 통해 같은 파일을 읽고, 네이티브 오류 화면에도 같은 파일을 내장합니다. HTML 안에 별도 색상 토큰을 덧붙이지 않습니다.

상태색은 성공·대기·실패를 구분하기 위한 의미색입니다. 텍스트와 상태 이름을 함께 표시합니다. 세션 아이콘은 금색·아이보리·보조색만 사용하며 이전의 보라·분홍·파랑 개별 세션 색 캐시도 교체합니다. 그래프 면·상태 배경은 정본 색의 12~16%, 강조선은 35~45%, 중립 트랙은 아이보리의 7%를 사용합니다. 상세 패널 덮개는 바탕색의 70%, 스킬 대화상자 덮개는 검정의 50%, 그림자는 검정의 40~50%입니다.

Pretendard와 기존 시스템 글꼴 대체, 본문 14px·보조 12px, 간격 4·8·12·16·20·32px, 카드 반경 16px·입력 4px·버튼 5px는 유지합니다. 포커스 테두리는 금색 2px입니다. 기본 조작은 금색 테두리, 선택 상태는 따뜻한 표면과 금색 테두리, 활성 스위치 손잡이는 먹색으로 충분한 대비를 확보합니다.

앱 표시 이름은 Huginn이며 실행 식별자·DB 경로·기존 `wb` 명령·서비스 주소는 유지합니다. 네이티브 창의 초기 배경은 `bg`와 같은 먹색을 사용합니다.

## 시안 비교 문서

형태 5종과 Crossing 색상 5종의 기존 비교 HTML은 검토 기록으로 보관합니다. 최종 제품은 사용자가 선택한 Twins 원본을 따릅니다.

2026-11-19에는 단독 까마귀·두 까마귀·매듭·뿌리·문장 5개 방향을 단일 HTML로 비교했습니다. 이미지가 문서 안에 포함되어 있으며 밝은/어두운 배경, 16·32·64px, 원본 확대를 제공합니다. 이 문서는 승인 당시의 비교 기록으로 유지하며 제품의 공통 색상 파일과 연동하지 않습니다. 뿌리형 후보의 짙은 녹색 `#13221f`도 비교 이미지에만 사용합니다.

## macOS 드래그 설치 창

DMG는 Finder의 실제 `Huginn.app`과 `Applications` 폴더 바로가기를 표시합니다. 두 아이콘을 배경 이미지에 그려 넣지 않습니다. 새 까마귀 앱 아이콘을 쓰며 볼륨 아이콘도 같은 ICNS를 사용합니다.

기본 밝은 Finder에서도 파일명이 읽히도록 배경은 아이콘의 아이보리에 맞춘 `#ece5d5`, 제목과 화살표는 먹색 `#24221d`, 보조 문구는 `#625b4e`입니다. 먹색·금색 `#a88b4f`은 제목 위의 짧은 선에 사용합니다. 그라데이션·카드·그림자·마케팅 문구는 추가하지 않습니다.

| 요소 | 값·배치 |

배경 정본은 `packaging/macos/render_background.py`이며 위 배치를 1배·2배 PNG와 멀티 해상도 TIFF로 생성합니다. TIFF를 숨김 `.background` 폴더에 넣고, 마운트된 볼륨 안에서 생성한 Alias로 연결하여 다른 Mac에서도 찾을 수 있게 합니다. `.DS_Store`는 직접 생성하며 Finder UI 자동화에 의존하지 않습니다. 배경만의 미리보기와 마운트된 이미지의 파일·배치 검증을 구분해서 보고합니다.

## 위임 작업

부모 상세에서 위임 목록은 기본 접힘이며 사이드바에 완료 알림을 추가하지 않습니다. 목록 머리에는 개수와 작업/대기 상태를 작은 선 아이콘과 텍스트로 표시합니다. 항목을 열면 위임 지시와 결과가 나란히 보이고 좁은 화면에서는 세로로 쌓입니다. 긴 원문은 내부 스크롤하며, 기록이 없으면 미확인으로 표시합니다. 기존 Pretendard·본문 14px·보조 12px·간격 8/12/16/20px와 표면색을 재사용합니다. 원문은 HTML로 실행하지 않고 텍스트로 표시합니다.
