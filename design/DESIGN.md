# Forkrail 디자인 기준

이름은 **Forkrail**입니다. Fork는 병렬로 갈라지는 작업, Rail은 작업의 진행 경로를 나타냅니다. 여러 AI 세션의 진행과 맥락을 사람이 따라가는 앱입니다.

## 앱 아이콘

사용자가 확정한 디자인은 **Crossing · Signal**입니다. 두 개의 굵은 직각 경로가 중앙의 사각 빈 공간을 두고 맞물립니다. 오른쪽 위는 시안, 왼쪽 아래는 노란색이며 바탕은 짙은 남색입니다.

| 요소 | 기준색 |
| --- | --- |
| 바탕 | `#102231` |
| 오른쪽 위 경로 | `#64D9F5` |
| 왼쪽 아래 경로 | `#FFD36B` |

정본은 `app/brand.json`이 가리키는 `app/assets/forkrail-icon.png`입니다. 사용자가 선택한 색상 시안 원본을 그대로 사용합니다. 경로의 비율·방향·중앙 빈 공간·겹침을 유지하며, 새로 그리거나 다른 심볼로 치환하지 않습니다. 원본의 얕은 겹침 그림자를 유지하고 타일 밖은 투명하게 둡니다. 글자·네온·유리 효과·장식 요소를 추가하지 않습니다.

웹 로고·파비콘과 macOS 아이콘은 같은 원본을 사용합니다. Swift 빌드는 AppKit으로 필요한 해상도와 ICNS 형식만 생성합니다. `scripts/build_app.sh`는 웹에서 쓰는 128px 파생본도 함께 갱신하며, 이 파일은 직접 수정하지 않습니다. 생성 방식과 프롬프트는 `app/assets/icon-prompt.txt`에 있습니다. 변경 후 16·32·128px 축소본과 밝고 어두운 배경에서 확인합니다.

## 화면

기존 화면의 Pretendard, 다크 배경 `#0c0e16`, 표면 `#14171d`, 텍스트 `#eeeeee`, 기본 강조색 `#4c6df1`을 유지합니다. 간격은 4·8·12·16·20·32px, 카드 반경은 16px, 입력은 4px, 버튼은 5px입니다. 아이콘의 시안·노란색은 브랜드 이미지에 사용하며, 화면의 상태색이나 버튼색으로 확장하지 않습니다.

앱 표시 이름은 `app/Info.plist`, 화면 표시 이름은 HTML 제목과 헤더에 적용합니다. 실행 식별자, DB 경로, 기존 `wb` 명령, 서비스 주소는 표시 이름과 분리합니다.

설정의 동작 버튼은 기존 `soft-button`을 사용합니다. 현재 단계의 주 동작은 `settings-primary`의 강조 테두리를 적용하고, 함께 표시하는 보조 동작은 `settings-secondary`의 `--dim` 테두리로 구분합니다. 테두리는 1px이며 버튼 반경 5px를 유지합니다. 업데이트 확인→다운로드→설치처럼 단계가 바뀌면 주 동작의 강조도 함께 이동합니다.

## 시안 비교 문서

형태 5종과 Crossing 색상 5종의 기존 비교 HTML은 검토 기록으로 보관합니다. 최종 제품은 위의 Crossing · Signal 원본을 따릅니다.

비교 HTML은 위 다크 화면 값을 따릅니다. 밝은 배경 확인용 색상은 배경 `#f4f4f0`, 표면 `#ffffff`, 텍스트 `#14171d`입니다. 시스템 글꼴을 사용해 파일 하나만으로 열리게 하며, 본문 14px, 보조 12px, 시안명 20px, 제목 32px를 사용합니다. 시안은 같은 크기와 여백으로 제시하고 16·32·64px, 회색조, 밝고 어두운 배경을 비교합니다. 시안 이미지의 색상은 조작부의 강조색과 구분합니다.
